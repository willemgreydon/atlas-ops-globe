# Legal / operational notes

A globe like this is mostly a data-licensing and reliability project, not a rendering project.

- Verify redistribution rights for every provider. Commercial ADS-B/AIS/news feeds often restrict caching, public display, derivative products or redistribution.
- Preserve attribution required by OpenStreetMap and other map/data providers.
- Sanctions data should be treated as source data, not as a legal conclusion. Display list, program, authority and retrieval time.
- Conflict and breaking-news events can be wrong or incomplete. Show source, freshness and confidence; avoid presenting inferred claims as facts.
- Public-person entity enrichment should use public information and reputable sources. Keep provenance and avoid private-person tracking.
- Consider delaying or aggregating sensitive live asset locations where provider terms, security policy or law requires it.
- Build source-health monitoring: API latency, last successful ingest, gap detection, quota usage, schema drift and token expiry.
