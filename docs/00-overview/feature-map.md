# Feature map extracted from the screenshots

## Clearly visible

1. Full-screen interactive 3D earth / globe with country outlines and per-country color states.
2. Satellite/cloud/weather-like raster texture layered over the globe.
3. Top navigation with mode tabs such as **Conflict**, **Live Tracking**, and **Contamination**.
4. Global market/status ticker across the top (S&P 500, NASDAQ, single equities / directional deltas).
5. Geographic alert markers drawn as concentric rings / hotspots.
6. Clickable event cards anchored to geographic positions.
7. Active-alert overlay with event class, headline, time, confidence and intensity.
8. Country detail panel (example: Iran) including flag, critical state, country code and narrative assessment.
9. Country economic / national-debt metric.
10. Donut / categorical composition visualization.
11. Sanctions narrative with multiple sanction frameworks / jurisdictions.
12. Strategic chokepoint monitor for the Strait of Hormuz.
13. Embedded live ship-traffic map.
14. Vessel/day, transits in 24h, annual transit volume and cargo-mix metrics.
15. Dark-vessel / AIS-off metric.
16. Click-through vessel detail: vessel name, type, navigation status, speed/course, draught and recency of AIS observation.
17. Side rail with mini time-series / sparkline cards for multiple monitored indicators.
18. Bottom scrolling headline/status tape.
19. Premium/account state in header.
20. Geographic focus and drill-down from globe -> country -> local asset/event.

## Strongly implied by the UI

- real-time or near-real-time ingest
- source fusion across geopolitical, finance, sanctions, transport, meteorology and news feeds
- layer toggles and thematic filtering
- severity and confidence scoring
- entity linking by country/person/organization/vessel/aircraft
- temporal filtering and playback
- alert subscriptions
- source provenance / evidence links
- a normalized global event graph rather than independent widgets
